## 🚀 Projetos

### [SemanaZero](https://www.semanazero.com.br/)
SaaS de gestão para personal trainers autônomos e academias, em beta aberto e gratuito.

O treinador monta treinos personalizados por aluno, e o aluno acompanha a própria evolução em gráficos. Tem mapa muscular visual mostrando o que cada treino trabalha e um feed social interno para manter o pessoal engajado, que é o ponto onde a maioria dos apps de treino falha.

Dois perfis de acesso, Aluno e Gestor. Não existe autocadastro: o aluno só entra depois de ser cadastrado pelo personal ou pela academia, o que mantém a base limpa e o vínculo com quem paga pela plataforma.

`Nuxt 4` `Vue 3` `TypeScript` `Tailwind CSS v4` `Supabase` `PWA`

[Acessar](https://www.semanazero.com.br/)

### [Compra Certa](https://compra-certa-tau.vercel.app/)
Lista de compras para usar dentro do mercado. Guarda o preço pago em cada compra e avisa na hora se um item está mais caro que da última vez, com aba de gastos mostrando a evolução dos últimos seis meses.

Funciona offline: as alterações entram numa fila persistida e sobem sozinhas quando a rede volta, porque sinal dentro de supermercado é ruim. Tem gestos de arrastar para marcar e remover, e 53 testes cobrindo comparação de preço, formatação e a lógica da fila offline.

`Nuxt 4` `TypeScript` `Turso (SQLite)` `Tailwind` `shadcn-vue` `Google OAuth` `PWA` `Vitest`

[Acessar](https://compra-certa-tau.vercel.app/) · [Repositório](https://github.com/Lucasvicentedasilva/compra-certa)

### [NotchKit](https://notchkit.vercel.app/)
App de widgets para Windows, feito com Tauri e Vue.js. Nasceu como projeto pessoal para resolver um incômodo meu de produtividade e hoje está em beta público. É o que eu uso todo dia.

`Tauri` `Vue.js` `Rust` `TypeScript`

[Acessar](https://notchkit.vercel.app/)
